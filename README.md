# 📘 Pokédex

## Nome do projeto

**Pokédex**

## ❓ Problemática

Encontrar e consultar informações de diferentes Pokémon de forma organizada, permitindo pesquisar suas características e comparar seus dados.

## 🎯 Objetivo da aplicação

Desenvolver uma Pokédex responsiva utilizando React, permitindo visualizar informações dos Pokémon, realizar pesquisas, adicionar favoritos e comparar Pokémon.

## 🛠️ Tecnologias utilizadas

- React
- Vite
- JavaScript
- CSS3
- Axios

## 🌐 API utilizada

Foi utilizada a **PokéAPI** para obter os dados dos Pokémon, como nome, imagem, número, tipos, habilidades e estatísticas.

## ⚙️ Principais funcionalidades

- Exibição dos 60 primeiros Pokémon;
- Pesquisa por nome;
- Pesquisa por tipo em português ou inglês;
- Pesquisa por habilidade;
- Adição e remoção de favoritos;
- Comparação entre dois Pokémon;
- Layout responsivo para desktop, tablet e celular.

## ▶️ Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/bella-souza/pokedex
```

Entre na pasta do projeto:

```bash
cd pokedex
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```
